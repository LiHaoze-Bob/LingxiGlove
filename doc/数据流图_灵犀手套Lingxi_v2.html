⚡ 端侧（Edge）—— 低延迟 + 离线可用
  • Rule-based 识别：MPU6050 pitch/roll 硬编码规则，零模型依赖
  • Edge Impulse 1D-CNN：12K 参数，INT8 量化后 12 KB，~15 ms 推理
  • MotionDetector 门控：加速度方差 + 陀螺仪模长双阈值滞回，静止时跳过识别
  • 离线 TTS 兜底：断网时按 label 查表播放预录 PCM
☁ 云端（Cloud）—— 强语义 + 大模型能力
  • Qwen-LLM 改写：「我-要-水」→「我要喝水」，语义补全 + 口语化
  • Qwen-TTS 合成：24 kHz 高质量语音，支持多音色（Cherry / Ethan 等）
  • 阿里云 ASR：一句话识别，支持中文实时转写
  • LittleFS 缓存：命中时延迟从 3-5 s 降至 <100 ms

LingxiGlove_APP
实时对话 + 工程仪表板
Next.js + React + WebSocket，手套遥测数据实时上行。左侧对话气泡展示手势识别与语音ASR结果，右侧仪表板呈现系统健康、手势Top-3候选、5路弯曲传感器数据、麦克风PTT状态与频谱可视化。

LingxiGlove_Capture
跨平台采集与打标桌面应用
Tauri 2.x + Rust + React，取代 capture_serial.py 多步CLI流程。支持左右手双设备并行采集、uPlot 60fps实时可视化、统一打标、自动切窗、一键直传 Edge Impulse，实现端到端数据闭环。

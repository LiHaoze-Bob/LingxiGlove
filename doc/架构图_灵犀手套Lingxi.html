架构亮点：采用"边缘感知 + 云端认知"的混合智能架构。端侧 TinyML 负责低延迟手势识别与音频采集，云端 LLM 与 ASR 负责高层次的语义理解与语音转写。双向交流闭环填补了现有手语辅助设备仅支持单向翻译的空白。

FreeRTOS 任务调度器 + 消息队列 (Queue) + 环形缓冲区 (Ring Buffer) 双核 ESP32-S3：Core 0 运行 WiFi/BT 协议栈 | Core 1 运行用户任务
调度策略：传感器采集任务与音频采集任务保持最高优先级，确保数据不丢失；手势推理与语音识别任务运行在第二优先级，利用 FreeRTOS 消息队列实现任务间解耦；网络通信与输出驱动为事件触发，仅在需要时唤醒，降低平均功耗。
